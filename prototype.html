一、产品定位与核心竞争力
🎯

产品定位

面向全阶段健身人群的 AI 智能训练助手，从新手到老手全覆盖。核心理念：发掘个人潜力，为了自己而练。

AI 个性化 伤病感知 科学训练
💡

核心竞争力

市面上健身 App 都没有把「伤病恢复 + 体态矫正 + 个性化分化训练 + AI 智能分级」整合在一起。这是我们的差异化壁垒。

智能分级校验 伤病自动归类 6套主题系统
👥

目标用户

健身人群（新手到老手），年龄 18-55+。男女双维度主题适配，不同年龄段不同审美风格。

18-30 青年 31-45 中年 46+ 成熟
二、竞品分析

Keep

优势
用户量大、课程丰富、社区活跃
劣势
无 AI 智能分级、伤病模块薄弱、计划模板化

薄荷健康

优势
饮食数据库完善、热量计算精准
劣势
训练功能弱、无分化训练、无体态矫正

Builder（我们）⭐

优势
AI 智能分级 + 伤病感知 + 个性化分化 + 3D 解剖图 + 6套主题
差异化
唯一整合「训练+饮食+伤病+体态+AI校验」的健身 App
三、功能优先级矩阵
功能模块 具体功能 优先级 说明
用户档案 性别/年龄/身高/体重/PR数据 P0 必须 所有功能的数据基础
AI 智能分级 新手/进阶/老手自动校验 P0 必须 核心差异化功能

伤病恢复 自由描述+自动归类+康复动作 P1 加分 差异化亮点
训练理论 次数区间/大小肌群/皮质醇警示 P1 加分 教育价值，体现专业性
主题系统 性别×年龄 6套主题+自定义 P1 加分 UI 差异化亮点

七、技术架构
⚛️

前端框架

Next.js 16 + TypeScript + Tailwind CSS v4，App Router 架构，支持 SSR/SSG。

Next.js 16 TypeScript Tailwind v4
🎨

主题系统

CSS Variables 实现 6 套主题动态切换，支持用户自定义背景色、主题色、排版密度、卡片风格。

CSS Variables ThemeProvider localStorage
🧠

AI 能力

智能分级算法（4维度评分）、Mifflin-St Jeor 公式计算 BMR、关键词匹配自动归类伤病。

智能分级 BMR 计算 关键词归类

数据存储

localStorage 本地存储用户档案和设置，无需后端，零成本部署。

localStorage 无后端 零成本

部署方案

Vercel 一键部署，自动生成可访问链接，支持自定义域名。

Vercel CDN 加速 自动 HTTPS
🎤

特色功能

Web Speech API 语音输入伤病描述，SVG 肌肉解剖图可视化，日历同步训练计划。

语音输入 SVG 解剖图 日历同步
